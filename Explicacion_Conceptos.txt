EVIDENCIA Y EXPLICACION DE CONCEPTOS
PRACTICA 11 - NOMINA MENSUAL
CURSO: PROGRAMACION II

1. ARREGLO SIMPLE Y ARRAYLIST
Para los meses use un arreglo simple de tipo String llamado MESES que tiene los 12 meses del año ya guardados. Como la cantidad de meses no cambia, el arreglo es de tamano fijo y para mostrar el mes que pide el usuario utilizo el indice MESES[numeroMes - 1].
Para los trabajadores use una coleccion ArrayList llamada nomina. Elegi ArrayList porque la cantidad de empleados no es fija y puede ir aumentando conforme se registran. Para guardar cada empleado use el metodo add() y para saber cuantos empleados llevo registrados use el metodo size(). Para mostrar la lista completa en el reporte recorri el ArrayList utilizando un ciclo for de tipo for-each.

2. CLASE ABSTRACTA Y METODOS ABSTRACTOS
Cree la clase Empleado como una clase abstracta porque representa la base de cualquier trabajador, pero no se debe instanciar directamente con new Empleado. En esta clase declare los metodos abstractos calcularPago() y obtenerTipo(), para obligar a que las clases hijas definan su propia logica de calculo y su tipo.

3. HERENCIA Y SOBREESCRITURA (@OVERRIDE)
Las clases EmpleadoFijo y EmpleadoPorHora heredan de la clase base Empleado usando la palabra extends. Ambas subclases utilizan la anotacion @Override para sobreescribir los metodos calcularPago() y obtenerTipo(). Por ejemplo, EmpleadoFijo calcula el pago sumando el sueldo mas la bonificacion, mientras que EmpleadoPorHora multiplica el pago por hora por las horas trabajadas.

4. POLIMORFISMO
En el programa guardo los dos tipos de empleados (fijos y por hora) dentro de la misma lista ArrayList de tipo Empleado. Cuando imprimo el reporte de la nomina, recorro la lista y llamo al metodo calcularPago() de cada objeto. Gracias al polimorfismo, Java reconoce automaticamente que formula ejecutar segun el tipo de empleado que sea, sin necesidad de usar condiciones como if, switch o instanceof para decidir el calculo.

5. ENCAPSULAMIENTO Y ACCESO
Todos los atributos de las clases (dpi, nombre, sueldoMensual, bonificacion, pagoPorHora y horasTrabajadas) los declare como private para proteger los datos y evitar que se modifiquen directamente desde fuera. Para consultar la informacion desde otras clases use metodos de acceso getters como getDpi() y getNombre().

6. CONSTRUCTORES, PARAMETROS Y ARGUMENTOS
En cada clase cree constructores con parametros para recibir los datos iniciales al momento de crear el objeto.
- Parametro: Es la variable declarada en la definicion del constructor, por ejemplo "String dpi" en la clase Empleado.
- Argumento: Es el valor real que le paso cuando instancio el objeto con new, por ejemplo el numero "1234567890101" ingresado por el usuario.
Dentro de los constructores use la palabra this para diferenciar los atributos de la clase de los parametros que reciben el mismo nombre, por ejemplo this.nombre = nombre. Ademas, en las clases hijas use super(dpi, nombre) para enviarle los datos comunes al constructor de la clase padre Empleado.

7. AMBITO Y ALCANCE DE VARIABLES
En el codigo aplique diferentes niveles de variables:
- Atributo: La variable nomina de tipo ArrayList declarada a nivel de clase en Main, la cual se puede utilizar en todos los metodos de esa clase.
- Parametro: La variable mensaje en el metodo capturarDoublePositivo(String mensaje), la cual solo existe dentro de ese metodo mientras se ejecuta.
- Variable local: La variable totalNomina declarada dentro del metodo imprimirNomina(), la cual solo existe durante la ejecucion de ese bloque de codigo y desaparece al terminar.

Realice la comprobacion requerida en la guia con los siguientes datos:
